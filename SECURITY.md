# 安全报告 / Security

当前仅针对 main 分支和最新开发版本评估安全修复，没有承诺响应时限或旧版本支持周期。
Security fixes are assessed for main and the latest development version. No response SLA or older-version support window is promised.

**不要在公开 Issue 或 PR 中披露漏洞利用步骤、凭据或受影响用户信息。**
**Do not disclose exploit details, credentials or affected-user data in public issues or PRs.**

本仓库目前为私有；已有协作者可先建立仅含概述的 Issue，联系维护者 @Dashmett 安排私密报告渠道。即使是私有 Issue，也不要粘贴真实令牌或 Cookie。非协作者请先通过维护者已公布的联系方式请求安全渠道，不要通过普通公开问题发送细节。本项目目前未核实可用的专用安全邮箱或 GitHub 私密漏洞报告入口，不应假定存在。

This repository is currently private. Existing collaborators may open a summary-only issue to arrange a private reporting channel with @Dashmett; never paste live tokens or cookies, even into private issues. Other reporters should request a secure channel using contact details the maintainer has published. A dedicated security email or GitHub private vulnerability reporting endpoint has not been verified; do not assume one exists.

准备脱敏的版本信息、影响范围、最小复现条件和建议修复。正式公开仓库前，应先配置并验证私密报告渠道，再更新本文件。
Prepare redacted version information, impact, minimal reproduction conditions and any suggested fix. Configure and verify a private reporting channel before making the repository public, then update this file.
