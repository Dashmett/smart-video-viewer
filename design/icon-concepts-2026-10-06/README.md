# Safari 工具栏图标概念稿

仅用于选型，不是已安装图标。四份 SVG 为黑色透明底，24×24 设计网格。HTML 是浅色、深色和小尺寸对比示意，不代表 Safari 实际渲染。

1. 聚焦：推荐，四角与播放符号。
2. 影院：圆角宽屏与播放符号。
3. 环流：开放圆环与播放符号。
4. 浮窗：前后两层视频窗口。
